# Практична робота 1 — SQLite
## Варіант 1: Бібліотека

Створено таблицю `books` у базі даних `biblioteka.db` та додано 6 записів.

## Пояснення типів даних

- **id — INTEGER PRIMARY KEY.** Цей стовпець зберігає цілі числа та є унікальним ідентифікатором кожної книги. `PRIMARY KEY` не дозволяє повторювати ідентифікатори, а SQLite автоматично призначає значення, якщо його не вказати.
- **title — TEXT.** Назва книги зберігається текстом, оскільки може містити літери, пробіли та інші символи.
- **author — TEXT.** Ім’я та прізвище автора є текстовими даними, тому для них використовується `TEXT`.
- **publication_year — INTEGER.** Рік видання є цілим числом, без дробової частини.
- **genre — TEXT.** Жанр книги записується словами, тому тип `TEXT` підходить для цього стовпця.
- **copies_count — INTEGER.** Кількість примірників — це ціле число. Дробові значення тут не потрібні.

SQLite використовує type affinity — рекомендований тип зберігання для стовпця, але типізація SQLite є гнучкішою, ніж у багатьох інших СУБД.

## Контрольні питання

**1. Чому SQLite називають файловою, безсерверною СУБД?**  
SQLite зберігає базу даних у звичайному файлі, наприклад `biblioteka.db`. Для роботи не потрібно запускати окремий сервер. Програма звертається безпосередньо до файлу бази даних.

**2. Яка різниця між CLI та DB Browser for SQLite?**  
CLI дає змогу виконувати SQL-команди через командний рядок і зручний для швидкої роботи та автоматизації. DB Browser for SQLite має графічний інтерфейс, у якому простіше переглядати таблиці, дані та виконувати запити.

**3. Що таке type affinity в SQLite і чим вона відрізняється від типізації PostgreSQL?**  
Type affinity — це рекомендація щодо типу даних, які зберігаються у стовпці SQLite. SQLite може зберігати значення іншого типу, якщо це дозволяють правила. PostgreSQL має більш строгий контроль типів і зазвичай не дозволяє записувати несумісні значення без перетворення.

**4. Чим `id INTEGER PRIMARY KEY` відрізняється від звичайного INTEGER?**  
`INTEGER PRIMARY KEY` у SQLite є ключем рядка (rowid), має бути унікальним і не може бути NULL. Якщо значення не вказати під час вставки, SQLite зазвичай автоматично присвоює новий номер. Звичайний стовпець `INTEGER` таких властивостей сам по собі не має.
